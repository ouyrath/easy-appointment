# Easy Appointment

A mobile-first appointment booking PWA inspired by the simple multi-step flow used by modern appointment websites.

## Included
- Location selection and search
- Service selection
- Date and time selection
- Contact form
- Confirmation number
- Appointment lookup on the same device
- Installable PWA support
- Responsive phone/tablet/desktop layout

## Important
This starter version stores appointments only in the user's browser using localStorage.
For real public use, connect the form to a database (for example Supabase) and add email/SMS confirmations.

## Deploy
This is a static website. Upload the folder to Vercel, Netlify, Cloudflare Pages, or another static host.
